# 月饷定价：对照秦汉唐宋明的真实兵饷

> 问题：1 两/兵/月贵不贵？按兵种拆 0.6 / 1 / 1.5 是否合理？
> 结论：**1.5 两不贵，且有明代、清代史料直接对应；0.6 / 0.9 / 1.5 三档正好压在史料区间内。**
> 状态：已按兵种落地并上线（未推 GitHub）

---

## 一、史料里的兵饷（按月）

| 时代 | 兵种 | 月饷 | 出处 |
|---|---|---|---|
| 汉 | 边塞戍卒 | 月食粟约 3 石上下（另给少量钱） | 居延汉简研究（[CNKI 摘要](https://wap.cnki.net/touch/web/Journal/Article/JJSZ202201014.html)） |
| 明（万历二十五年，山东） | 土兵 | **0.90 两** | 彭勇论文（[PDF](https://ming.cnhis.ncnu.edu.tw/wp-content/uploads/2022/01/ming37_03Peng_full.pdf)） |
| 明（万历二十五年，山东） | 南兵 | **1.50 两** | 同上 |
| 明（卫所制） | 军 | 月粮 **1 石**（米） | 明代卫所月粮通例 |
| 清（绿营） | 守兵 / 步兵 / 马兵 | 约 **1 两 / 1.5 两 / 2 两** | 地方志「俸饷」志（[广西地方志·军事志](http://lib.gxdfz.org.cn/view2022-a70-42.html)） |
| 清（湘军，厚饷） | 勇丁 | **4.2 两** | 曾国藩厚饷练兵（[CCTV 讲武堂](http://cctv.cntv.cn/lm/jiangwutang/20140307/102966_2.shtml)） |

**换算到我们这个世界的粮价（0.6 两 = 1 石米）：**

```
0.6 两/月 ≈ 1 石米   → 与明代卫所"月粮一石"同档
0.9 两/月 ≈ 1.5 石米 → 与明万历山东土兵同档
1.5 两/月 ≈ 2.5 石米 → 与明南兵 / 清绿营步兵同档
4.2 两/月 ≈ 7 石米   → 湘军厚饷，属于"高薪募勇"，我们不采用
```

## 二、所以定这三档

| 名目 | 月饷 | 史料对应 | 我为什么这么定 |
|---|---|---|---|
| **家丁** | 0.6 两 | 明代卫所月粮一石 | 私兵、看家护院，管饭为主，饷薄 |
| **护院** | 0.9 两 | 明万历山东土兵 0.90 | 精壮能动手，给到土兵水准 |
| **营兵** | 1.5 两 | 明南兵 1.50 / 清绿营步兵 1.5 | 能出征的野战兵，给到南兵水准 |

**你之前说"1.5 贵了吧"——其实 1.5 在明代是"南兵"（精锐）的标准饷，
清代绿营步兵也是 1.5 两。真正贵的是湘军 4.2 两。**

## 三、口粮也按史实调了

```
明卫所：月粮一石
→ 我们改成 0.03 石/兵/日（≈0.9 石/月）
```

**原来 0.02 石/日（0.6 石/月）偏少，一个兵一个月吃不到一石米。**
