# 未婚女子池 —— 整改报告

> 问题：全城人物一排下来全是"已婚"，能遇见的未婚女子几乎没有，后宫与开枝散叶无从谈起。
> 状态：**已修并上线；线上未婚女子 16~28 岁共 13 人**
> 回归：`python scripts/regress.py` → **20/20**；未推 GitHub

---

## 一、病因（三层，都在）

1. **旧规则把成年人都判成已婚**
   早先 `≥24 岁 → married`，一次迁移把全城成年人都写成了已婚，
   之后每次读档都看到 `marital` 已有值，直接跳过。
2. **重判只跑过一次，而且只改了 1 人**
   我上一版加的一次性重判（`maritalRecheckV2`）条件太窄（非亲眷、无配偶、18~45），
   而且已经执行过，不会重跑。
3. **人口补充只看"16~30 岁未婚"总人数，不分男女、门槛太低**
   池子里有 12 个男性也算达标，于是永远不补姑娘；且每月最多 3 人。

---

## 二、改法

### ① 一次性重判 v3：把被误判的年轻人放回未婚池

```
只动：非内眷、无配偶、无身孕、非通房侍妾、16~29 岁、当前是 married 的人
判定：按名字哈希决定（不随机，同一人每次读档结果一样）
  女：≤19 岁 85% 未婚｜≤23 岁 75%｜≤27 岁 55%｜≤29 岁 35%
  男：≤22 岁 70%｜≤26 岁 45%｜其余 20%
结果：线上一次放开 8 人
```

### ② 人口补充改为"未婚女子池"

```
只看：16~28 岁、未婚、女性
目标：18 人（低于就补）
每月最多补 5 人（原来 3 人，且不分男女）
新人：卖花女 / 绣坊帮工 / 酒肆帮佣 / 医馆学徒 / 巷口洗衣女 / 茶摊看摊…
      年龄 16~24，婚配未婚，站在街上
女性比例 75%
```

### ③ 开局播种 + 一次性补足

```
开局若无未婚女子 → 直接播 12 人（一次性）
本次补足到 14 人（一次性）
之后由每月补人维持 18 人
```

### ④ 顺手修了一个性别错判

```
张彪（护院教头）被当成了女子
修法：名字里带 彪/虎/龙/刚/强/勇/铁/军/武/雄/豪/霸/峰/磊/鹏 的一律男子
      身份带 教头/武师/镖师/捕快 也一律男子
      heal 会把已错的纠正回来
```
