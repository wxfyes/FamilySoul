## 二、第一刀：物候 + 物价

### 物候（`season.js`）

| 规则 | 数值 | 依据 |
|---|---|---|
| 冬天运河封冻 | `canalFrozen = true` | `season === 'winter'` |
| 水路生意（栈/运/漕/码头/船） | 进项 ×0.35 | 封河停航 |
| 茶（春/冬） | ×1.15 / ×0.85 | 春茶贵、冬茶贱 |
| 酒（冬） | ×1.2 | 冬令旺 |
| 行军 | 冬天 ×2，雨雪再 ×1.5 | 雪阻道路 |
| 灾后疫病 | 灾荒当日 25% 起疫，全城民心 +5 | 大灾之后必有大疫 |
| 军械 | 按铁价指数浮动（0.7~2.5） | 缺铁则军械贵 |

### 物价（`prices.js`）

```
六类商品：粮 0.6 / 茶 1.2 / 丝 3.0 / 盐 0.8 / 铁 1.5 / 药材 0.9（常价）
世界物价指数：每日向 1 回归 8%
冲击：灾荒 → 粮 ×1.25/次、药 ×1.15/次
     战事 → 粮 ×1.1、铁 ×1.15
     秋收 → 粮 ×0.85
     冬天 → 粮、盐各 ×1.02
城价 = 常价 × 指数 × 城景气（0.7~1.6）
```

**实测**：

```
粮价基准 0.6 → 灾后指数 ×2 → 1.2 两/石
购粮 50 石：按临江府价扣 24.5 两（不再是写死的 0.6×50）
```

**接进哪：** 产业日入（物候系数）、购粮（按城价）、秋粮折银（同一套粮价体系）、军械（铁价）。

## 三、第二刀：岁时

```
每 30 个世界日，长一岁
五十之后体魄渐衰（100 → 每岁 -3）
十五及冠（发 coming_of_age 事件）
孩子分段：襁褓(≤3) → 垂髫(≤9) → 总角(≤13) → 束发(≤14) → 及冠/及笄(15+)
六十之后每年有概率病故（先标 sick，由既有生死逻辑收尾）
heirsOf()：按年岁排继承顺位
```

**实测**：本地推进 30 日，相公 27 → 28 岁。

## 四、第三刀：道统

```
名声 fame.value（-100 ~ 100）
标签：仁商 / 义士 / 权臣 / 乱贼（到门槛才贴，不会一出场就是乱贼）
名分 legitimacy = 名声/2 + 城数×5 + 20
```

**入口：**

```
POST /api/world/charity  { amount, city }
  施粥：花钱 → 城民怨降（amount/20）→ 名声涨（≤12）
  实测：施粥 100 两 → 名声 0 → 10
```

**后果（已接）：**

```
断交            → 名声 -6（乱贼标签）
称制（proclaim） → 名分 < 40 直接驳回，且名声 -10、朝廷关系 -80
每月初一        → 士林清议事件（只报事实："士林称道王甯的仁义"）
```

## 五、第四刀：宗族

```
自动按姓氏聚族：同姓 ≥2 人即成一族（沈氏/林氏/王氏…）
产业 ≥3 处 → 自动生成「临江商帮」
每月初一：宗族走动
   名声 ≥30 → 关系 +3；≤-30 → -4；否则 +1
   关系 ≥60 且 50% 概率 → clan_visit（族老登门求你提携后辈）
   关系 ≤25 且 40% 概率 → clan_cold（市井传闲话）
clanBacking()：关系 ≥50 时宗族为你出头（给影响力）
```

**实测**：本地世界自动生成 5 族（沈氏/林氏/王氏/陆氏/商帮），
名声 55 时触发「士林称道王甯的仁义」。
