## 每个子系统的验收规范

**必须能说出"我做了什么 → 世界怎么变"**：

```
✅ 好：我替她还了债 → 她信任+10，关系网里她对我更亲，街面风评变好
❌ 差：我替她还了债 → 她说"谢谢相公"（只有一句话，账本没动）
```

**一个子系统算完成，要同时满足**：

1. 状态里有字段（账本记了）
2. 有人能看到（看板或 App）
3. 有东西因它而变（别的系统读了它）

## 铁规：测试数据不许进生产

- 所有验收测试一律在临时目录（`os.tmpdir`）里跑，**绝不往生产 `state.json` 写测试数据**
- 若已误写：用管理接口清除（`/api/admin/case/remove`、`/api/admin/todo/remove`、`/api/admin/actor/delete`），并在日志里留一行说明
- 每加一个写接口，都要能回答：这条数据是谁写的、什么时候写的、怎么撤
