# 入账资格（四本账）

> 原则：什么能进哪个账，先定清楚，再写入口。入口只有一个，校验也只有一个。

## 一、地点账 `world.places`

**收**：铺面、房间、宅院、街巷、码头、衙门……
**不收**：付款话术（"付3两"）、数量词（"几个"）、动作（"开房"）

校验：`isPlaceNameOk()`（`src/world/ledger-rules.js`）
- 名字带 `付N两`、量词、指示词 → 拒绝

## 二、产业账 `world.assets.properties`

**收**：能做生意、有铺号的东西（铺/号/栈/坊/楼/店/行/庄/堂/馆/局/肆/轩/斋/园/场）
**不收**：
- 客房/上房/厢房/卧房/雅间（是住的地方，不是产业）
- 量词名（"几个铺子"）
- 账单式名字（"付3两"）

校验：`isBusinessName()`
- 长度 2~12、必须含铺号字、排除房间与账单词

## 三、人物账 `world.actors`

**收**：有人名、有身份（role）、有住处（home）、有来历（origin）的人
**不收**：没有名字的"某人"、重复的人、凭空补出来的"数字兵"

规则：
- 铺面配人由 `ensureShopStaff()` 在城生成时统一做
- 护院家丁按兵额收口，多余遣散为百姓（不删人）
- 家仆（household）只认本宅的人；户主（householdOwner）只落在本宅

## 四、银钱账 `world.ledger`

**收**：有来路的银两进出，必须能归入类别：

```
收入：进账 / 产业进项 / 卖米 / 走货回银 / 赌坊赢钱 / 缴获 / 俸禄 / 赏赐 / 收租
支出：买米 / 走货本钱 / 赌坊输钱 / 打点官府 / 客栈上房 / 雇佣 / 工钱 /
      房租 / 租铺 / 开销 / 税 / 罚银 / 采购 / 军械 / 募兵 / 聘礼 / 抚恤
```

校验：`moneyCategory()` 自动归类；账目标题带"付N两"这类话术时，一律改写为"进账/开销"。

## 五、谁在写

| 账 | 唯一入口 |
|---|---|
| 地点 | `ensurePlace`（城生成）/ `/api/admin/actor/move`（管理建位，已加名称校验） |
| 产业 | `dispatch.js` 的 `kind==='property'`（已用 isBusinessName 校验） |
| 人物 | `city.js` 的 `ensureShopStaff` / `spawnHouseholdStaff` / 迁入流程 |
| 银钱 | `ledger.js` 的 `appendLedger`（spendSilver/earnSilver 也走它） |

**模型不写任何一本账；它只能提议，由引擎校验后入账。**
