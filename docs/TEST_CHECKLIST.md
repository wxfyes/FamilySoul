# 相公真机验收清单

> 用法：一次只测一条。记下「时间 + 原话 + 期望 + 实际」，不对就贴给 AI。
> 测完一条打勾；不按顺序跳着测，避免东一锄头西一榔头。

## A. 移动 · 转场 · 在场（最高优先）

- [ ] A1 手动出门：点任一地点「前往」→ 顶部地点变、聊天出现「你到了…」
- [ ] A2 回家：点「回家」→ 回正房，不是大门
- [ ] A3 同场所领路：在货栈/客栈/茶坊说「带我去…」→ 两人一起进雅间，`此处` 有对方
- [ ] A4 点名地点：在书斋说「带我去茶坊」→ 去茶坊，不是书斋
- [ ] A5 跨场所领路：在货栈说「带我去王宅」→ 到王宅；同行人跟着
- [ ] A6 找人：点「找人」找在场/不在场的人 → 玩家走过去，不是把人召来
- [ ] A7 召唤：对真人角色点召唤 → 应提示「只能去找」，不能硬拉
- [ ] A8 门禁：去别人宅院 → 门房拦在大门，头顶地点是「大门」，不是空白/原始 id

## B. 钱 · 账本（错一次就伤经济）

- [ ] B1 收定金：收到「五十两定金」递信，回「好的/收下」→ 现银 +50、流水 1 条
- [ ] B2 重复确认：再回一次「好」→ 不再加钱、不再多流水
- [ ] B3 尾款：次日寿宴办完 → 尾款 +110 一次，且只一次
- [ ] B4 否定句：「不用招家丁」「别买丫鬟」→ 不扣钱、不添人
- [ ] B5 招募：「招两个护院吧」→ 真招；人不在场时应提示，不隔空扣钱
- [ ] B6 日入：新开产业后「日入」变化；一次性定金不应算进日入

## C. 承诺 · 约定 · 差事

- [ ] C1 到期未办：次日对方来问「可还作数」
- [ ] C2 已办：差事办完 → 相关承诺自动消失
- [ ] C3 过期：超过到期日 1 天未办 → 自动作废并留「旧诺过期」
- [ ] C4 约定：约定「后天晌午」→ 到点有人来/有提示
- [ ] C5 差事跨天：夜里派差 → 当晚不瞬移，次日才动身
- [ ] C6 借款：借钱/还钱/免债 → 流水与承诺同步

## D. 剿匪 · 军事 · 风评

- [ ] D1 剿匪授官：累计到门槛 → 回复/事件里有「升授…」
- [ ] D2 风评：剿平后看板「街面风评」→ 60 人知，不是 0
- [ ] D3 缴获：银/粮/降卒入账各一次，兵账与真人一致
- [ ] D4 战败：折兵有记录，不凭空全灭
- [ ] D5 月饷/月耗粮：看板数字 = 兵种×月饷、人数×日粮×30

## E. 地点 · 家宅 · 人口

- [ ] E1 于家酒肆：只有前堂/后堂，不再有「三层天字阁」
- [ ] E2 大酒楼：三层/天字阁/雅阁正常存在，能进
- [ ] E3 正房：只有家人，家丁/护院在大门或议事厅
- [ ] E4 新地点：领路到没去过的小店 → 能生成雅间，不报错
- [ ] E5 头顶地点：任何页面都应显示中文地名，不是 `xxx__hall` 原始 id
- [ ] E6 人物生成：主动递信里提到的「账房/大厨/汪总商」若出现，应是真人 actor，点得开

## F. 聊天质量 · 语音

- [ ] F1 同场多人：只让相关的人接话，不排队报幕/不复读「是！」
- [ ] F2 不在场：提到不在场的人，不该凭空插话
- [ ] F3 分角：每条都有【身份·名字】，不出现裸冒号/英文 id
- [ ] F4 记忆：隔几轮再问同一件事（银/粮/约定）→ 数字与说法一致
- [ ] F5 语音：婉儿/芸娘/小翠各回一句 → 三种音色，不串音
- [ ] F6 系统提示：`【提示】` 与角色台词分开，不重复同一动作

## G. 多人 · 真人角色

- [ ] G1 离线：真人在线状态为离线时，AI 可代说、可同场所同行
- [ ] G2 在线：真人一登录，AI 不再代说/代走
- [ ] G3 可找不可召：任何真人角色都只能去找，不能被召来
- [ ] G4 上线交还：AI 代走的位置，本人上线能看到

## H. 稳定性 · 看板

- [ ] H1 重启：stop/start 后地点、银两、承诺不丢
- [ ] H2 并发：连点两次「前往」/连发两条消息 → 不重复扣钱、不卡死
- [ ] H3 看板：官职/兵马/月饷/风评/最近战报与 `/api/me` 一致
- [ ] H4 长聊：连续 20 轮后仍记得开头的事，不崩

**当前建议先测 A1–A8**：移动/在场是最近改动最多、也最容易连锁出问题的一层。
