# 律法与天听（Law & Heaven's Hearing）设计稿

> 定位：律法是天道之下、万民之上的一条硬规则。
> 这个世界可以发生犯罪——但犯罪逃不掉；律法不看身份，只看证据。
> 天道是暗处的眼，不是判官；它负责"看见"，不负责"代替证据定罪"。

## 一、宗旨

1. **法在权上**：皇帝、官员、豪强、百姓，同一套律法。皇帝犯法，走"天宪"程序，不许私埋。
2. **犯罪可以存在，代价必须落地**：虚拟世界不回避犯罪题材；但犯罪必有案件、有追查、有判决、有刑罚。
3. **证据说话**：孤证不立；口供不能单独定案；伪造证据、诬告都要反坐。
4. **程序不可跳**：报案 → 受理 → 勘验 → 取证 → 审讯 → 判决 → 复核。少一步，判决无效。
5. **已决案件原则上不翻**；只有"天听"能翻。翻案后，因果链上的审判者一个都跑不掉。
6. **天道不替人定罪**：模型只能审查证据是否足够、程序是否有猫腻；定罪必须落到 `world.law` 的证据上。

## 二、现状与差距

当前 `world.cases` 只有：

- `generateCase()` 生成一桩"谁告谁"；
- `judgeCases()` 让模型输出 `{verdict, reason, penalty}`；
- 没有证据链、没有复核、没有诬告反坐、没有天听。

这套只能算"说书判案"，撑不起"律法最高神明"。

## 四、证据规则

1. **孤证不立**：判有罪至少需要两类独立证据（如物证 + 人证），或一类物证 + 勘验记录。
2. **口供不能单独定案**：只有供词 → 证据不足，判无罪或继续查。
3. **刑讯有代价**：刑讯得到的供词标记 `torture: true`，可信度下降；若因此错判，主审加罪。
4. **伪证可造也可破**：伪造证据由模型/仵作/书吏按技能与程序识破；识破后原告按"诬告反坐"处理。
5. **证据要落地**：证据必须来自世界里真实存在的人/物/地点；模型不得凭空补一条"其实有账本"。

## 五、审判流程

| 阶段 | 谁做 | 产物 |
|---|---|---|
| 报案 | 原告 / 苦主 | `case.reported` 事件 |
| 受理 | 地方官 | 受理或驳回；驳回要写理由，可越级 |
| 勘验 | 仵作 / 捕快 | 现场记录、尸检、物证 |
| 取证 | 捕快 / 书吏 | 人证、书证、物证入 `evidence` |
| 审讯 | 主审官 | 供词（自愿/刑讯） |
| 判决 | 主审官 | `verdict`：罪名、刑罚、引用的证据 id |
| 复核 | 上级 / 大理寺 | 维持 / 驳回重审 |
| 执行 | 官府 | 笞杖徒流死、抄没、连坐 |
| 天听 | 天道 | 复查已决案件，或驳回"表演式喊冤" |

每一步写事件流，案件状态只前进不跳跃；跳步的判决一律无效。

## 六、天听（Heaven's Hearing）

### 触发

有人在公堂、刑场、府衙前，发自内心喊出"冤枉""老天开眼"一类话，进入 `天听` 候选。

### 查两件事

1. **是否真冤**：调案卷、对证据、查孤证/伪证/刑讯；
2. **是否真心**：看前后因果、是否有人教唆、是否表演。

### 判定

| 情况 | 结果 |
|---|---|
| 真心 + 真冤 | 天象异动（雷雨/异象/民心），案件进入 `reopened`，重查 |
| 不冤 + 表演喊冤 | 欺天：罪加一等；或引出新的告发者/证人 |
| 真心 + 确实有罪 | 不翻案；从轻发落其"自首"情节，但罪不减 |
| 已决 + 真冤 | 翻案昭雪；按因果链追责审判者 |

### 天道边界

- 天听可以**看见**证据，但不能**凭空造**证据；
- 天听可以**怀疑**判决，但不能只凭一句"冤枉"就定罪官员；
- 翻案必须有新证据或原案证据链断裂，否则不予受理。

## 七、因果追责

翻案后，按因果链分层：

| 角色 | 情形 | 后果 |
|---|---|---|
| 主审 | 受贿、枉法、刑讯致死 | 丢官、抄没、流放、病死（重） |
| 复核 | 明知有疑仍维持 | 贬官、罚俸、名声受损（中） |
| 批准 | 压案、销毁证据 | 与主审同罪（重） |
| 证人/仵作 | 作伪证 | 诬告反坐；仵作除名 |
| 被胁迫者 | 不知情、被逼画押 | 从轻，或免罪 |

后果分日展开，不一夜全死；但"因果链上的一个都跑不掉"是硬规则。

## 八、权力与皇帝

### 官员

- 官员有 `integrity`（操守）、`faction`（派系）、`greed`（贪欲）；
- 受贿会改变判决倾向，但会留下痕迹（账目、证人、御史风闻）；
- 压案不是"消失"，案件仍可越级、京控、御史弹劾；压案本身成为罪。

### 皇帝

- 一般案件，皇帝不亲审；
- 涉及皇帝本人的重罪，走 **天宪**：
  - 三法司 + 御史台联合立案；
  - 至少三类独立证据；
  - 天听记录在案，不可销毁；
  - 定罪后，天下震动（朝局、兵变、民心），执行不是一句话的事。
- 天宪的意义：**法在君上**；但执行要考虑世界的政治后果，不是自动斩首。

## 九、刑罚

- 笞、杖、徒、流、死（明律五刑）；
- 抄没、连坐、除籍、枷号；
- 天道附加：丢官、破产、病亡、断子绝孙（叙事后果，按因果与情节推进，不滥用）。

## 十、大模型的角色

模型 = **监控 + 审计**，不是判官。

每次判决前后，模型只做四件事：

1. 证据是否够（孤证/口供/伪证）；
2. 程序是否跳步（有没有勘验、复核）；
3. 供词是否刑讯所得；
4. 判决理由与证据是否对得上。

模型输出 `flags`（疑点清单），不输出"有罪/无罪"；最终判决由 `world.law` 的证据阈值与程序状态决定。

这样既保留"天道开眼"的戏剧性，又不会被模型的幻觉带偏。

## 十一、验收测试（世界动作级）

| 用例 | 断言 |
|---|---|
| 只有口供 | 判无罪/证据不足，不得定罪 |
| 物证 + 人证 | 可定罪；判决引用证据 id |
| 伪造证据被识破 | 原告按诬告反坐 |
| 县令受贿压案 | 案件不消失，可越级；压案成为罪 |
| 真心喊冤 + 真冤 | 案件 `reopened`，天象事件出现 |
| 表演喊冤 + 有罪 | 罪加一等，或出现新告发者 |
| 已决冤案翻案 | 因果链审判者分层受罚 |
| 皇帝涉案 | 仅天宪可立案；无三类证据不受理 |

## 十二、落地顺序

1. **证据与判决**：`src/world/law.js`，替换 `judgeCases()` 的模型直判；
2. **程序与复核**：受理、勘验、复核、越级；
3. **天听**：喊冤触发、复查、翻案、追责；
4. **天宪**：皇帝/权贵案件的特殊程序；
5. **测试**：`scripts/test_law_actions.mjs`，临时世界跑全流程。
