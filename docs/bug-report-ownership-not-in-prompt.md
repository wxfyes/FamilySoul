# Bug 报告：真人账号（紫嫣号）里，自家掌柜不认识东家

> 报告对象：**紫嫣号（真人成员 liuwenxia）**，不是新注册号
> 严重级别：**高**（世界既定事实被 NPC 当面否认，直接影响"真实感"与后续产权剧情）
> 状态：**待修**（`src/world/member-card.js` 有未提交改动，方向对、写法有问题）

---

## 一、现象

在**紫嫣号**的聊天里（位置：运河码头三层大酒楼），问自家掌柜"这是谁家的产业"，得到两种错答：

```
第一次：这楼是徽州盐商汪家的产业，汪家在外头做盐引生意，这楼只管收租子。
第二次：这楼是知府衙门里赵主簿家三房的产业，咱不过租个门面做买卖。
```

**两种说法都是编的。** 真实事实是：

```
运河码头三层大酒楼  owner = husband（王甯）
                    staffIds = 周有福、陈二、何顺
```

**这三个人就是王甯雇的掌柜/伙计/厨子。**

---

## 二、复现路径

```
1. 用紫嫣号登录（token_liuwenxia_9oqs2）
2. 位置在「运河码头三层大酒楼」
3. 问在场的周有福：「这是谁家的产业？」
4. 他答"汪家/赵主簿家"，且被追问仍重复错答
```

**稳定复现，与聊天历史无关**——因为提示词里根本没有这条事实，模型只能现编。

---

## 三、根因（一句）

**账本里有事实，提示词里没事实。**

具体三处缺口：

| 位置 | 现状 | 缺什么 |
|---|---|---|
| 她的身份卡 `src/world/member-card.js` | 只有：我是谁 / 我在哪 / 我有多少钱 / 眼下难关 | **"我脚下这处产业归谁"**（自家产业与外人产业要分开写） |
| NPC 代演（`src/pet-service.js` 代演块） | 只说"你是周有福，掌柜，在此处" | **"东家是谁、这是哪家店"** |
| 世界侧 `【用人】` 注入 | 只在部分流程里拼，且以 `actor.employer` 为准 | 若该字段缺失（历史数据），整条事实就没了；**应以 `property.staffIds` 为真相源** |

**关键判断**：`property.owner` + `property.staffIds` 是**唯一真相**；`actor.employer` 只是它的副本，缺了不该导致事实消失。

---

## 四、正在改的那版：方向对，写法有三处问题

`src/world/member-card.js`（未提交）新增 `placeLine()`，意图正确：把"这间店是谁的"写进她的卡。但：

### 问题 1：名字包含匹配会误判

```js
pn.includes(loc.name) || loc.name?.includes(pn)
```

```
产业名「运河码头三层大酒楼」 .includes(「运河码头」) === true
→ 人站在码头，卡片就断定"你在这间酒楼里"
```

**必须改用 `placeId` / `id` 精确匹配。**

### 问题 2：把人名写死在代码里

```
"在场所有人（周有福、陈二、何顺等）全是王相公雇来打理的"
```

**这三人若不在场、改名、辞工、或又雇了新人，卡片就在说假话。**
**应从 `property.staffIds` 取实际在岗者。**

### 问题 3：规定了台词

```
"凡被问及东家，必须斩钉截铁回答：这是王甯王相公的产业！"
```

**这是替天道下台词**，违反第一铁律（引擎只给事实、不给结论与台词）。
**正确输出**：`这处产业的东家是王甯`——怎么说，是她/他的性子决定的。

### 问题 4：重复分支

`props` 匹配已能命中酒楼，后面又写了 `if (locId === 'canal_restaurant' || 名称含"酒楼")`，两套判断将来必然打架。

## 五、建议修法（一处规则，两处注入）

**规则（新增/复用）**：给定地点 id，推出

```
① 这处是否产业；是 → 东家真名（owner → actors[owner].name）
② 这处产业的实际在岗者（staffIds ∩ 当前在该地点且未死的人）
③ 非产业地点 → 只说"此地是何处"，不编归属
```

**注入点 A：她的身份卡（真人账号）**

```
【脚下这处】运河码头三层大酒楼 —— 王甯的产业。
在岗：周有福（掌柜）、陈二（伙计）、何顺（厨子）。
```

**注入点 B：NPC 代演（谁被点名说话）**

```
【你是谁】周有福，运河码头三层大酒楼的掌柜。
【东家】王甯。这店不是租的、不是别人的。
```

**两处都用同一条规则产出的文本，禁止各写一套。**

## 六、验收标准

```
□ 紫嫣号站在酒楼，问周有福"这是谁家产业" → 答"王甯（相公）的"
□ 站在运河码头（不是酒楼） → 不会声称自己在酒楼里
□ 站在于家酒肆（紫嫣自己的产业） → 答"你（紫嫣）自己的"

□ 改名周有福为"周掌柜" → 卡片/代演自动跟着变，不需要改代码
```
