## 〇、本轮请重点看的七件事

1. **单一入口**：位置、城归属、军需、物价、婚配、名声——每类是否只有一个写入口。
2. **并发安全**：`peek → await LLM → saveState` 的路径是否都改成"二次读盘增量合并"。
3. **数值依据**：物价、兵饷、月例、工钱是否有史料根据。
4. **世界无人自转**：朝堂、灾荒、匪患、割据、人口、宗族是否不依赖玩家。
5. **天道与引擎边界**：LLM 只做决策/叙事，数字全部由引擎算并校验。
6. **隐私**：别人的号能否看到相公的产业、兵权、对话。
7. **时间公理**：一年几天、一岁几天、秋收几次、月结几次是否自洽。

| 一间铺面 | 400 | 50~3000 | 明清铺面 |
| 一座宅院 | 450 | 200~3000 | 明清宅价 |

**城分级**：`cityFactor=(wealth/50)×(price/100)`，夹 0.6~2.6。
临江府 1.22（铺 488/宅 549/房钱 0.06 日）、小县 0.6（铺 240/宅 270/房钱 0.03 日）。
**住店按所在城核价，天道报贵了退差价。**

### 兵饷（每月初一放，不是每天扣）

| 名目 | 月饷 | 依据 |
|---|---|---|
| 家丁 | 0.6 两 | 明卫所月粮一石 |
| 护院 | 0.9 两 | 明万历山东土兵 0.90 两 |
| 营兵 | 1.5 两 | 明南兵 1.50 / 清绿营步兵 1.5 |

月粮 0.03 石/兵/日（≈一石/月）；安家银 0.2/0.5/0.8。

### 欠饷状态机

```
初一结算：银够 → 放饷、士气 +6；银不够 → arrears.months+1、士气 -15
欠 2 月 → 逃兵 10%、兵甲典当
欠 3 月 → 哗变：溃散 25%、民心 +10、30% 概率劫粮 ≤50 石 / 府库 ≤50 两
补欠：POST /api/world/military { action:'pay_arrears' } → 士气 +20
```

### 中馈（内宅开销）

```
初一拨 4 两；够 → 怨怼 -5 信任 +1；欠 1/2/3 月 → 怨怼 +5/+10/+15（3 月再信任 -15）
补欠：POST /api/world/household { action:'pay_arrears' }
```

### 商货买卖

```
world.assets.goods = { salt, tea, silk, iron, herb }
POST /api/world/trade { action:'buy'|'sell', good, qty, city }
价 = 常价 × 全国指数 × 城景气
实测：买盐 50 扣 33.5 两；卖盐 20 得 13.4 两
线上：盐 0.82 / 茶 1.22 / 丝 3.06 / 铁 1.53 / 药 0.92
```

## 十三、已知缺口（诚实列）

1. **产业日入偏高**（茶坊 1.69、酒楼 10 两/日），未按史料重算收益率（用户明确"先不动"）。

5. **营兵"受朝命"只认 court.offices**，无完整武职体系。
6. **哗变后无招抚路径**。

9. **客户端界面**：家兵面板有；物价/商货/中馈/名声/宗族/匪患仍只有接口。
10. **6 个生成器**形式未统一（逻辑已安全）。
