## 一、周老六：女 → 男（41 岁）

**病因**：开场由天道 spawn 的过门人，性别写的是 `'unknown'`；
后续没有任何地方把它补上，前端便按"非男"当成了女性。

**修法**（规则，不是个案）：

```js
inferGenderFromIdentity(name, role, fallback)
  名字带 娘/婆/姑/嫂/妹/姐/氏/妇… → 女
  身份含 丫鬟/婆子/妇人/绣娘/稳婆… → 女
  身份含 先生/公子/老爷/和尚/捕快… → 男
  都看不出 → 按 fallback（默认男）
```

**三处接入：**

```
开场 spawn（dm_opening）：不再写 unknown，直接推断
读档迁移：所有 gender 为空或 unknown 的，一律补
heal 自愈：同上，并把改动记进修复日志
```

**线上实测**：

```
周老六｜male｜41 岁｜已婚
```

## 三、"全城女人都已婚"——这是真问题

**病因**：旧规则 `≥24 岁 → 一律已婚`。
一个 24 岁的姑娘在旧规则里必是"人妇"，于是全城几乎无未婚女子。

**新规则（按年纪与性别分层）：**

| 年龄 | 结果 |
|---|---|
| <18 | 未婚（除非通房/侍妾 → 妾室） |
| 18~23 | **七成未婚**、三成已婚（名字带"娘子/嫂/婶"的算已婚） |
| 24~29 | **五成未婚**、五成已婚 |
| 30~44 | 九成已婚、一成寡居 |
| ≥45 | 六成老伴在堂、**四成寡居** |

**并且做了一次性重判**（旧规则判过的也要纠正）：

```
[Persona] 按世情重判婚配 1 人
```

**另加"人口补充"规则**（避免可遇之人太少）：

```
每月初一，若 16~30 岁未婚的人不足 12 个 → 补 1~3 个
来历都是市井活人：卖花女、绣坊帮工、酒肆帮佣、医馆学徒、脚夫、货郎、船工…
年龄 16~24，婚配未婚，放在街上
并发一条市井风闻："市井又来了几张新面孔：某某、某某"
```

**说明**：这些人不是为你准备的，就是城里新来的活人；你能不能遇上、她看不看得上你，是另一回事。

## 四、兵制：月饷制 + 一呼百应（不是买断）

### 你说得对：买断就等于永久兵，军饷成了摆设

**改成：**

```
募兵不再"花 12 两买一个人"
  安家银：家丁 0.2 两、护院 0.5 两、营兵 0.8 两（一次性，意思一下）
  月饷：1 两/兵/月（每日结算 1/30 ≈ 0.033 两）
  月粮：0.6 石/兵/月（每日 0.02 石）
```

**所以：**

```
100 兵 = 每月 100 两饷、60 石粮
发不出 → 士气跌 → 逃兵（这套早就在跑）
```

### 招募改为"一呼百应"

```js
callToArms(world, 势力, { 城, 上限, 名目 })
  来投人数 = 3 + 名声/6 + (50-民怨)/4 + 城富庶/20
            × 运气(0.6~1.4)
            ≤ 你喊的上限
```

**含义：**

```
名声 0、城里安稳 → 你喊 30 人，可能只来 4 个
名声 60、民心稳、城富 → 你喊 30 人，可能来 40 个（被上限截住）
```

**实测（本地）**：名声 0 时喊 30 人 → **来投 4 人**，扣安家银 0.8 两。

### 面板与聊天都改了

```
App：按钮从"募家丁"改为「招募家丁」「招募护院」
     三宫格第三格从"存粮"改为「月饷」（显示每月要发多少两）
     底部一行：存粮 X 石 · 月饷 Y 两/月 · 月粮 Z 石/月

聊天："去招二十个家丁" → [[recruit:20]] → 待确认单（写着月饷）
     确认后按一呼百应结算："来投 N 人，成军七日，月饷 X 两"
```
