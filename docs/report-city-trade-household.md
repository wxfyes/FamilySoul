## 一、② 房价地价按城分级

### 城的等级因子

```js
cityFactor = (wealth / 50) × (price / 100)   // 夹在 0.6 ~ 2.6
房价（铺/宅）= 常价 × 城因子
房钱（住店） = 上房常价（0.05 两/日）× 城因子
```

### 实测

| 城 | 城因子 | 一间铺面 | 一座宅院 | 房钱/日 |
|---|---|---|---|---|
| 临江府（wealth 60 / price 102） | 1.22 | 488 两 | 549 两 | 0.06 两 |
| 小县（wealth 25 / price 90） | 0.6 | 240 两 | 270 两 | 0.03 两 |

**住店时按所在城核价**：天道若报 3 两，引擎会按城价结算并退差价（不再出现"一晚三两"）。

## 二、③ 盐、茶、丝、铁、药 真的能买卖

### 数据结构

```js
world.assets.goods = { salt: 0, tea: 0, silk: 0, iron: 0, herb: 0 }
```

### 接口

```
POST /api/world/trade { action:'buy'|'sell', good:'salt|tea|silk|iron|herb', qty, city }
```

### 价格来源

```
市价 = 常价 × 全国物价指数 × 城景气（prices.priceAt）
灾荒 → 粮/药涨；战事 → 铁涨、粮涨；秋收 → 粮落
```

### 实测（本地）

```
买盐 50 → 扣 33.5 两（0.67 两/单位），手里盐 50
卖盐 20 → 得 13.4 两，手里盐 30
负载：{ stock:{salt:30}, prices:{盐 0.67, 茶 1.01, 丝 2.52, 铁 1.26, 药材 0.76} }
```

**线上实时价**：盐 0.82 / 茶 1.22 / 丝 3.06 / 铁 1.53 / 药材 0.92。

**这意味着"囤盐等灾、贩茶赶春"第一次真的成立了。**

## 三、方案三支柱

### 支柱一：中馈月例银（内宅开销不再靠天道空想）

```
每月初一（day % 30 === 0）：
  公中拨 4.0 两给内宅（world.assets.householdAllowance）
  银够 → 扣银、发事件「月初发下公中月例银 4 两，内宅井井有条」
         眷属怨怼 -5、信任 +1
  银不够 → 欠饷式危机：
    欠 1 月：怨怼 +5，事件「主母暗中典当贴补米面」
    欠 2 月：怨怼 +10，市井开始传「王家手头紧」
    欠 3 月：怨怼 +15、信任 -15，「丫鬟告假离府，内宅生计维艰」
```

**补欠接口：**

```
POST /api/world/household { action:'pay_arrears' }
  欠多少补多少，补完眷属怨怼 -10、信任 +5
  文案：「补发内宅积欠 X 两，婉儿重掌中馈，家宅复归安泰」
```

**负载**：`household: { allowance, arrears, silver }`

## 五、还没做 / 需要你定

1. **产业买价仍用既定数值**（酒楼 510、王宅 450），没有按城因子重算——
   历史既定事实我不动；若你要"按城重新估值"，需要一次产业重估。
2. **商货没有"库存上限/仓储费"**，理论上可以无限囤。
3. **商货买卖只走玩家**，NPC 商贩还不会自己进货出货（物价仍由指数驱动）。
4. **中馈 4 两/月**是估值（约 6.7 石米），若按明制内宅开销可再压到 2 两。
5. **中馈只有"发/欠/补"**，还没有"婉儿拿钱买了什么"的具体采买事件。
