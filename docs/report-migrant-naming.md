# 来客由天道定名 · 由事定量 · 落脚三日 —— 整改报告

> 上一版被指"配额补人"是补丁。这一版把三处补丁味一次清掉：
> ① 名字由天道定；② 来几个人由灾情/产业/商路算，不掷概率；③ 来人有落脚处。

---

## 一、① 名字：引擎不再起名

### 旧做法（补丁味）

```
引擎用百家姓随机拼名字 → 直接造人
```

### 现在（分工）

```
引擎只登记"有人要来"：
  world.pendingMigrants = [{ 缘由, 行当, 性别, 约岁, 盘缠, 落脚处, 来的日子 }]
  （不建角色、不起名）

天道定名（每次心跳，最多 3 人）：
  提示词：「第N日，临江府来了这些人：1. 逃荒来的妇人（女，约33岁）…」
  要它回：{"people":[{"index":1,"name":"周苹","age":33,"background":"淮北逃荒来的，带着一个孩子"}]}
  → 引擎把名字、岁数、来历落进角色（background 字段）

兜底：连续 3 天没有天道应答（无 LLM/失败），引擎才用最朴素的名字把人落下，
      不允许出现"来了人却查无此人"
```

**所以：人是谁、叫什么、什么来历，是天道定的；引擎只负责"确实有人来了"。**

---

## 二、② 来多少人：由事算，不掷概率

| 缘由 | 现在怎么定量 |
|---|---|
| 邻道灾荒 | **按灾荒起数**：本月有 N 起灾，就登记 N 个逃荒者（上限 4） |
| 招工 | **按铺子缺人手数**：`staff < 3` 的产业有几处，就登记 ceil(缺/2) 人（上限 2） |
| 商路 | **不掷概率**：只要有城「富庶 ≥55 且民心 ≤30」，本月必来 1 个行商 |
| 投亲嫁娶 | **每季一次**（`day % 90 === 0`）且全城民心 ≤35 |

**旧的 15%/60%/50%/35% 全删掉了。** 现在"来几个人"能从世界状态推出来，
不是"我拍了一个概率"。

---

## 三、③ 落脚：来了先有地方去

```
逃荒 → 城隍庙/庙口（temple）
投工 → 街上（street）
行商 → 客栈（inn）
投亲 → 客栈（inn，先去落脚再找亲戚）

三天后（settleMigrants）：还没安家的，自己在城里安下身来
  → 发事件「某某在城里落下脚来」、标记 settled
```

**不会再出现"人凭空站在长街上、无家无业"。**

## 五、诚实说明

1. **本地验不到"天道定名"这一段**（本地没有 DeepSeek Key）；
   生产上要等下一次心跳才会看到 `[Migrate] 天道定名：某某（绣坊帮工）…` 的日志。
2. **背景只存了一句 `background`**，还没有接进"她跟谁有旧、住哪条街、靠什么吃饭"的完整档案。
3. **落脚处只做了四类**（庙/街/客栈/客栈），没有"投亲找亲戚"的具体过程。
