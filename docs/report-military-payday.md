## 二、现在的军制

### 日常：只吃粮，不动饷

```
每日：每兵吃 0.02 石（城仓先扣，不够吃随军粮）
粮不够 → 士气 -4、发「军中缺粮」
饷：一文不扣
```

### 放饷日：每月初一（`day % 30 === 0`）

```
应发 = 兵力 × 1 两
银够 → 扣银、士气 +6、发「放饷 X 两，军心大定」
银不够 → 进入欠饷状态
```

### 欠饷状态机

| 欠饷月数 | 后果 |
|---|---|
| 1 个月 | 士气 **-15**，发「欠饷 N 月（欠 X 两），营中怨声四起」 |
| 2 个月 | 再 **-15**，**逃兵 10%**，兵甲被典当（兵器同步减） |
| 3 个月以上 | **哗变**：溃散 25%，士气归 20，所驻之城民心 +10 |

### 补发积欠：有钱随时能补

```
POST /api/world/military { action:'pay_arrears' }
  欠多少补多少，补完士气 +20、欠饷清零
  补清时发「补清积欠，营中欢声雷动」
```

## 四、为什么这套比"日扣"更像古代

```
① 平时不摸钱：大帅身上没钱也不影响军队吃饭
② 初一放饷：银箱抬到校场、点名发饷，这才有画面
③ 欠饷才出事：先怨、再逃、后哗变，有三档缓冲
④ 补饷能救：筹到钱立刻回血，军政博弈活了
⑤ 数字极简：1 两/兵/月，一看就懂
```
