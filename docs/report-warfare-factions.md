## 二、势力表（数据结构层）

本来世界里已有一份 `world.factions`（临江府衙 / 朝廷权贵 / 运河漕帮 / 临江王家），
但只有 `{name, relation, power, cities}`——**没有兵、粮、士气、野心**。

这次不新建一套，而是**给既有势力补齐字段**（单一数据源）：

```js
f.id, f.kind ('court' | 'player' | 'clan')
f.leader            首领（actorId 或 'court'）
f.troops, f.grain   兵、粮（势力自己持有）
f.morale, f.ambition 士气、野心（决定敢不敢动）
f.stance            'defend' | 'status_quo' | ...
f.cities            名下的城（由 cities[].owner 反向同步）
```

**钱的唯一出处**（不重复记账）：

```js
朝廷   → world.court.treasury.silver（国库两）
王家   → world.assets.silver（家底）
其他   → f.silver
```

**战力公式**：

```
战力 = 兵数 ×（0.6 + 士气/100）×（训练/50）
```

## 三、兵权（经济与状态机层）

### 常量（可调）

| 项 | 值 |
|---|---|
| 募兵银 | 12 两/兵 |
| 募兵自带粮 | 0.5 石/兵 |
| 军饷 | 0.05 两/兵/日 |
| 口粮 | 0.02 石/兵/日 |
| 买粮价 | 0.6 两/石 |

### 每日结算（`clock.js` 每日一次，0 token）

```
有粮 → 扣粮；有钱 → 扣饷
两样都够 → 士气 +1
缺饷 → 士气 -6；缺粮 → 士气 -3
士气 < 25 且 50% 概率 → 逃兵 10%，士气回到 30
```

**事件**：`army_hungry`（军中缺粮）、`army_unpaid`（欠饷）、`desert`（逃兵）——都会进世界时间线。

### 实测（本地）

```
买粮 300 石 → 花 180 两，粮 300
募兵 60     → 花 720 两，兵 60，粮降到 270，士气 61
```

## 四、夺城（规则层）

```
围城：攻方派兵 → 战力 × 战场运气(0.8~1.3) 对比 城防(defense + 守军×1.2)
胜：城易主、城防降到 6 成、民心 +10、攻方士气 +5、兵力回补 75%
败：城防降到 8.5 成、攻方士气 -8、出兵全损
```

**城的归属只有这一个写入口**（`besiege` / `bribeCity`），别处不许改 `ct.owner`。

**招降**（花银子买通守将）：

```
成功率 45%；成功则城归你，失败则城防 +3（守将收了钱不认账）
```

**修城**（守）：花 200 两，城防 +6（上限 90）。

### 实测（本地）

```
60 兵打临江府：攻击 29 vs 城防 16 → 破城，临江府归王家
战后：兵 60 → 45（回补 75%），士气 66
```

## 五、天下推演（LLM + 规则双轨）

### 规则推演（无 LLM，0 token，每 7 日）

```
粮不足兵数一半 → 先囤粮，不打
野心不够（random > ambition）→ 按兵不动
否则找一座最弱、不属于自己的城，派一半兵去打
```

### 天道推演（有 LLM，每 7 个世界日一次）

**输入**（只给事实，不给结论）：

```
势力：id｜名｜兵｜粮｜银｜士气｜野心｜城数
城池：名｜归属｜城防｜民心｜富庶
```

**要求输出**（JSON 数组，最多 6 条）：

```json
[{"faction":"canal","action":"recruit","amount":40,"reason":"漕帮要扩充水手"}]
```

**允许的动作**：`recruit` / `buy_grain` / `besiege` / `bribe` / `fortify` / `hold`

**铁律**：天道只给决策，**引擎逐条校验**（钱不够、粮不够、兵不够，一律作废），**绝不允许它直接改数字**。

**实现位置**：`server.js` 的 `onAfterTick`，`flags.lastStrategyDay` 保证同一世界日只跑一次。

## 六、托管（玩家不在时）

```
玩家势力 stance = 'defend'
→ 规则推演只处理 kind !== 'player' 的势力，不会替玩家出兵
→ 玩家离线期间，世界照样推进，但不会拿你的兵去送死
```

**想参战，得自己下命令。这就是"你不参与，世界也走；你要参与，得自己动手"。**

## 九、还没做的（下一轮）

1. **外交**：结盟、背盟、附庸、共同出兵——现在只有打和买。
2. **自立建国**：势力扩张到一定规模后可称制/建国，旗帜、国号、法统；现在只能占城。
3. **枭雄自生**：无 LLM 时不会凭空长出新势力；LLM 推演也暂不允许创建新势力（怕失控）。
4. **App 界面**：兵权目前只有接口，App 里还没有「募兵/出兵」的按钮与地图。
5. **粮道与距离**：现在无视远近，兵可以从临江直接打太原；需要按路程与补给线限制。
6. **守军**：`city.garrison` 字段已支持，但还没有"募守军/调兵驻防"的入口。
