## 一、最严重的一条：任何人的号都能看到王甯的家产

### 病因（真 bug）

```
出门抽屉里的"我的产业"，读的是 /api/world/menu 的 homes 字段
而 menu 这段代码直接：
   const props = (world.assets?.properties || []).map(...)   ← 全量，不过滤
于是不论谁登录，都会看到王甯的六处产业
```

### 修法（单一入口，按身份过滤）

```js
const props = (world.assets?.properties || []).filter((x) => {
  if (!x) return false;
  if (actorId === 'husband') {
    return x.owner === 'husband' || x.keeper === 'husband' || (!x.owner && !x.keeper);
  }
  return x.owner === actorId || x.keeper === actorId;
});
```

**与 `/api/me` 里产业列表用的是同一条判定**，两处不再各写一套。

### 实测（本地）

```
相公自己的号：临江·王宅、临江茶坊老店、运河码头三层大酒楼、城南生药铺（4 处）
新注册的号：  （空）
```

## 二、家兵没有家丁、护院可买

### 病因

家兵面板只有「募兵 / 购粮 / 兵器 / 铠甲 / 战马 / 攻城器械」，没有"家丁""护院"这两个古代人真正会买的选项。

### 修法：募兵按名目分三类（同一个入口）

| 名目 | 每名安家银 | 随身粮 | 士气 | 用途 |
|---|---|---|---|---|
| **家丁** | 1.2 两 | 0.2 石 | +1 | 看家护院，最便宜 |
| **护院** | 3.0 两 | 0.3 石 | +2 | 精壮，能动手 |
| **营兵** | 4.0 两 | 0.4 石 | +3 | 能出征，要地盘 |

```js
recruit(world, fid, count, city, kind = 'guard')
   RECRUIT_KINDS = { guard: 家丁, retainer: 护院, army: 营兵 }
```

**三条通道都进同一个门：**

```
App 胶囊按钮：募家丁 / 募护院
聊天说"招十个护院" → [[recruit:护院|10]] → 待确认单 → 同一个 recruit()
天道推演 → 同一个 recruit()
```

## 三、兵价与物价不符合行情

### 原价（确实离谱）

```
募兵 12 两/人（古代募兵安家银约一两上下，12 两相当于半年饷）
兵器 3 两/件、铠甲 5 两/件、战马 20 两/匹、攻城器械 300 两/架
```

### 新价（按行情）

```
家丁 1.2 两/人     护院 3 两/人     营兵 4 两/人
兵器 0.6 两/件    铠甲 1.8 两/件
战马 9 两/匹       攻城器械 40 两/架
军饷 0.05 两/兵/日（约 1.5 两/月，与古代兵饷相当）
口粮 0.02 石/兵/日（约 0.6 石/月）
```

### 实测（本地）

```
募家丁 10 人 → 12 两
募护院 3 人  →  9 两
买兵器 5 件  →  3 两
买战马 1 匹  →  9 两
```

**同时保留了此前的行情机制：**

```
粮价按城价（0.6 常价 × 物价指数 × 城景气）
军械按铁价浮动（0.7 ~ 2.5 倍）
```
