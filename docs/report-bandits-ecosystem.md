## 一、落地了什么

### ① `src/world/bandits.js`（新模块）

数据：`world.bandits = { id: { name, kind, region, homeCity, leader, strength, tier, silver, grain, infamy, createdDay } }`

```
kind：water（水盗）/ mountain（山匪）/ horse（响马）—— 按城所在道与地形判
tier：1 阶（<50）流寇骚扰 ｜ 2 阶（≥50）立寨盘踞 ｜ 3 阶（≥200）聚众攻城
```

### ② 自然萌生（每月初一）

**不是"民怨≥50 就刷怪"，是四件事合起来：**

```
基础概率 0.05
+ 民怨/200（最高 +0.3）
+ 本月有灾荒 +0.15
+ 地形险要（山/岭/水/湖/泽/关）+0.05
+ 城防薄弱（<20）+0.03
同城只一股；每道最多三股（免得遍地开花）
```

**实测（本地第 600 日）**：生成 3 股
`临江府水帮（力23 阶1）`、`冀州府马帮（力28 阶1）`、`兰州府游骑（力34 阶1）`

### ③ 演变与官兵围剿（每月初一）

```
每月成长：+max(1, 民怨/10)，银粮同步涨，声名 +2
一阶：城价上浮（商道受阻）
二阶：该城民怨 +3（匪越做越大）
三阶：城防 <25 且匪力 > 城防×6 → 破城据守（接入割据）

官兵围剿：该城归属势力驻军 ≥ 匪力×1.5，且战力 > 匪力×1.2
  → 剿平、民怨 -10、通报「【官兵剿匪】XX守军剿平「XX匪」」
```

### ④ 相公剿匪（`POST /api/world/military { action:'quell_bandits' }`）

```
参数：{ action:'quell_bandits', banditId, troops, city }
校验：你在这座城有驻军
战阵：王家战力 × 运气 vs 匪力（阶越高越硬）
胜：
  · 剿平该股
  · 缴获全部赃银入公账、赃粮入城仓
  · 该城民怨 -20
  · 名声 +25（义士）
  · 首次剿平 → 朝廷授「临江府乡勇团练使」（world.court.offices.tuanlian）
    → 营兵门槛（据城或受朝命）就此合法打通
败：折兵 25%~40%，匪不减
```

**实测**：剿临江府水帮（力23）派出 150 人，因战力不足战败，折兵 2 人（战报如实）。
