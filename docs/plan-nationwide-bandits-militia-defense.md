## 零、最高第一铁律与第一性原理

1. **天下无人在场时自然自洽演化**：
   - 匪患不是围绕相公一个人刷怪，而是全天下 17 道根据当地的**天灾（`season.js` 旱涝封河）、民怨（`unrest ≥ 50`）、官府兵备（`defense` 与驻军）**自然涌现；
   - 强藩镇守之地官兵自发剿匪；贪官懦弱之地匪患越滚越大，最终聚众攻城甚至自立为割据反贼；
   - 相公初期在江南管不了北方，但在茶坊与市井中能听到天下邸报与商贾风闻；
2. **单一写入口与严格状态机**：
   - 匪患的生成、劫掠、壮大、被剿、溃散，全部由 `src/world/clock.js` 统一调度，绝不写死剧情；
3. **零多余 Token 消耗**：
   - 全天下的推演全在本地 Node.js 离线毫秒级计算，只有与相公直接相关、或产生重大天下变局时，才生成 1~2 行简短微型事件，绝不增加大模型上下文负担！

在 `data/world/state.json` 中统一挂接 `world.bandits` 字典，按地理据点管理：

```json
      "tier": 2,

```

### 属性定义：
- `kind`：`water`（水泊水盗，劫水路商船）、`mountain`（绿林山寨，收买路钱劫驿道）、`horse`（北方响马，游骑劫掠）；
- `tier`：匪患阶段（1~3 阶）；
  - **1 阶（流寇骚扰，兵力 20~50）**：劫掠散商，致使该城商道运费上涨 20%；
  - **2 阶（立寨盘踞，兵力 50~150）**：劫掠乡镇村落，该城民怨每月自增（`unrest +3`），商路受阻；
  - **3 阶（聚众啸聚，兵力 200~500+）**：声势浩大，开始攻打城防薄弱的县城，成功则占城为王（接轨 `strategy.js: maybeSpawnWarlord`）。

## 二、天道自治循环（`src/world/clock.js` 每月推演）

### 1. 自然萌生（`maybeSpawnBandits`）
- 每月（`day % 30 === 0`），遍历全天下 17 道各主要城池：
  - 若某城 `unrest ≥ 50` 且当地周边无同名山寨，有 30% 概率由逃荒饥民啸聚成寨（初阶流寇，兵力 30，携带微薄口粮）；
  - 自动根据地形赋予地名（江南依水成泽、江北傍山立寨、西北旷野响马）。

### 2. 天下博弈与官兵剿灭（`runBanditEcosystem`）
- **朝廷/地方势力反应**：
  - 拥有该城池的势力（`city.owner`）：
    - 若该势力在城中驻军 `troops >= bandit.strength * 1.5`：
      - 判定官兵出剿，双方计算战力损耗：
      - 官兵获胜：解散山寨，缴获财物归入官仓，该城 `unrest -= 10`，全天下通报：`【官兵剿匪】XX府守将剿平XX匪寇，地方复归安宁。`；
    - 若该城驻军空虚无力出剿（或为朝廷平庸昏官）：
      - 匪寇做大，每月滋长（`strength += Math.round(unrest / 10)`），向 2 阶、3 阶跃升！

## 三、相公保境安民通道（家丁护院的大用）

相公是江南乃至大争天下中的重要实体，有兵有权即可主动出击！

### 1. 求援风闻与市井请愿
- 当相公驻足临江府，且周边匪患达到 2 阶（或滋扰王家商道）时：
  - 运河船夫、临江茶商或苦主百姓涌向茶坊，生成天道公开事件：
    `【乡民求庇】紫阳山匪寇截断茶道，客商寸步难行，乡绅父老求告王相公主持大局。`

### 2. 相公出征剿匪接口（`src/server.js`）
- 提供通用军事行动接口：
  `POST /api/world/military { action: 'quell_bandits', banditId: 'bandit_ziyang', troops: 20 }`
  - 校验：
    - 调动相公所属势力（`wangjia`）在临江府驻扎的**家丁/护院**；
    - 校验粮食与随军战力（结合装备 `gear` 与士气 `morale`）；
  - 战阵推演（纯本地数值）：
    - 战力公式：`王家护院战力 vs 匪寇战力`；
    - 战胜判定：
      - 剿平该股匪患（山寨从字典中抹去）；
      - 伤亡极低（精装护院伤亡 5%~15%）；
      - **缴获山寨全部财宝**：缴获白银归相公资产，粮食充入府库；
      - **全城民心大振**：临江府民怨大跌（`unrest -= 20`），全城百姓交口称赞；
      - **相公名望暴涨**：`addFame(world, 'husband', 25, '保境安民')`；
    - **功名进阶（突破营兵门槛的关键！）**：
      - 剿匪大胜后，知府杨大人（或朝廷布政使）感念相公忠义勇武，由天道正式下达任命札子：
        `world.court.offices['tuanlian'] = { holder: 'husband', title: '临江府乡勇团练使' };`
      - **至此，相公正式拥有朝廷兵备武职，招募野战营兵（`army`）的门槛被堂堂正正合法打通！**
