# 人口从哪来：配额补人 → 由事出人

> 问题：上次修"未婚女子池"是不是又打补丁？
> 诚实回答：**是。** 那是"池子不够就补 N 个"的配额逻辑，外加两次一次性播种。
> 现在已改成 **由事出人**：灾荒才有流民、开产业才有人投工、商路才带客商、太平才有人投亲嫁娶。

---

## 一、先认错：补丁长什么样

```js
// 旧（补丁）
if (未婚女子 < 18) 补 min(5, 18 - 未婚女子) 个
```

**问题：**

```
① 原因是"人数不够"，不是"世上发生了什么事"
② 补出来的人没有来历，凭空出现在街上
③ 阈值一改，行为就变——像给仪表盘刷数，不是世界在动
```

---

## 二、现在：人只能因为"有缘由"才来（`src/world/migration.js`）

| 缘由 | 触发条件 | 来的是什么人 |
|---|---|---|
| ① 邻道灾荒 | 近 3 日有灾荒，或 15% 概率 | 逃荒妇人、带孩子的流民、逃荒汉子、流落老妇（盘缠 0.1 两） |
| ② 招工 | 自家产业 ≥3 处，60% 概率 | 绣坊帮工、酒肆帮佣、医馆学徒、脚夫、货郎、书铺学徒 |
| ③ 商路 | 有城富庶 ≥55 且民心 ≤30，50% 概率 | 行商、贩布客商、收山货的、贩盐的（盘缠 8 两） |
| ④ 投亲嫁娶 | 全城民心 ≤35（太平），35% 概率 | 投亲的姑娘、嫁到城里的新妇、随兄嫂迁来的 |

**每条缘由都会写进市井风闻**：

```
「商路太平，行商往来频繁：林茂」
「邻道有灾，逃荒的人进城讨口饭吃：周苹、钱桃」
```

## 三、引擎与天道的分工（这次分清了）

```
引擎（0 token）：什么时候来人、来几个、干什么行当、带多少钱
天道（LLM）    ：这些人叫什么、什么来历、跟谁有旧、怎么跟相公打交道
```

**也就是说：引擎给"事实"，天道给"人和故事"。**

**下一步可做（等你定）**：把"来的人"作为一条事实喂给天道，让它当场给他们起名、编一句来历，
而不是引擎用百家姓随机拼名——那才是"天道自己衍生"。

## 六、还剩的"补丁味"

1. **来人的名字还是引擎用百家姓拼的**，不是天道起的——这是下一步要接的。
2. **概率阈值（15%/60%/50%/35%）是我拍的**，没有史料；
   严格说该由"邻道灾荒严重程度、产业规模、商路等级"算，而不是固定概率。
3. **来人之后没有"落脚"过程**（投亲该找亲戚、逃荒该去粥厂），现在直接站在街上。
