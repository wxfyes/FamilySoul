## 三、经济：物价与兵饷（史料依据）

### 价目表（`pricing.js`，唯一出处）

| 项目 | 常价 | 区间 | 依据 |
|---|---|---|---|
| 客栈上房 | 0.05 两/日 | 0.02~0.1 | 明制一日几分银 |
| 客栈通铺 | 0.02 | 0.005~0.04 | 同上 |
| 一顿饭 | 0.02 | 0.005~0.05 | 明·数文至一分 |
| 一壶酒 | 0.05 | 0.02~0.2 | 明·酒价 |
| 腰刀 | 0.6 | 0.3~1.2 | 明·刀价 |
| 棉甲 | 1.8 | 1.0~3.0 | 明·甲价 |
| 战马 | 12 | 10~30 | 明·马价 |
| 攻城器械 | 40 | 20~80 | 云梯/冲车 |
| 短工日钱 | 0.04 | 0.02~0.08 | 明·短工 |
| 仆役月钱 | 0.5 | 0.3~0.8 | 明·长工年 3~5 两 |
| 一间铺面 | 400 | 50~3000 | 明清铺面 |
| 一座宅院 | 450 | 200~3000 | 明清宅价 |

**城分级**：`cityFactor = (wealth/50) × (price/100)`，夹 0.6~2.6。
临江府 1.22（铺 488 / 宅 549 / 房钱 0.06 日）、小县 0.6（铺 240 / 宅 270 / 房钱 0.03 日）。

### 兵饷（每月初一放，不是每天扣）

| 名目 | 月饷 | 依据 |
|---|---|---|
| 家丁 | 0.6 两 | 明卫所月粮一石 |
| 护院 | 0.9 两 | 明万历山东土兵 0.90 两 |
| 营兵 | 1.5 两 | 明南兵 1.50 / 清绿营步兵 1.5 |

**月粮**：0.03 石/兵/日（≈ 一石/月）。
**安家银**：家丁 0.2 / 护院 0.5 / 营兵 0.8（一次性，很小）。

### 欠饷状态机（`runPayday`）

```
每月初一：应发 = Σ 兵种×月饷
  银够 → 扣银、士气 +6、「放饷 X 两，军心大定」
  银不够 → arrears.months+1、owed+应发、士气 -15
    欠 2 月 → 逃兵 10%、兵甲典当（兵器同步减）
    欠 3 月 → 哗变：溃散 25%、所驻城民心 +10
              30% 概率洗劫：军粮 ≤50 石、府库 ≤50 两
补欠：POST /api/world/military { action:'pay_arrears' } → 士气 +20
```

### 中馈（内宅开销）

```
每月初一：公中拨 4.0 两给 household 眷属
  够 → 怨怼 -5、信任 +1
  欠 1/2/3 月 → 怨怼 +5/+10/+15；3 月再信任 -15
补欠：POST /api/world/household { action:'pay_arrears' }
负载：household:{ allowance, arrears:{months,owed}, silver }
```

### 商货（盐/茶/丝/铁/药）

```
world.assets.goods = { salt, tea, silk, iron, herb }
POST /api/world/trade { action:'buy'|'sell', good, qty, city }
价 = 常价 × 全国指数 × 城景气
实测：买盐 50 扣 33.5 两；卖盐 20 得 13.4 两
线上价：盐 0.82 / 茶 1.22 / 丝 3.06 / 铁 1.53 / 药 0.92
```

### 三个单一推导（`persona.js`）

```
inferGenderFromIdentity：名字/身份看不出女性特征 → 男（绝不留 unknown）
inferAgeFromIdentity：姓名+身份一起看
  婆/嬷嬷/老太/妪/翁/老汉 50~65｜婶/大娘/伯/鸨/知府 40~53
  嫂/妇/娘子/当家/掌柜 26~37｜丫鬟/书童/伙计 16~21｜婴/童/幼 5~13

  <18 未婚（通房/侍妾 → 妾室）
  18~23 七成未婚｜24~29 五成未婚｜30~44 九成已婚｜45+ 四成寡居

```
≥50 年长绝经·子息已毕｜<14 金钗幼女·尚未破壁｜有孕 身怀六甲·孕X月
经期 月事方至｜育龄 月事周期第 X 天（10~16 天标易受孕期）
月事结算只算 14~49 岁，绝经者残留数据清掉

### 人口与性别

```
天道 spawn：性别/年龄/婚配/盘缠/街坊关系 一次给全
月度补人：16~30 岁未婚不足 12 人 → 补 1~3 个市井新人（卖花女/绣工/帮佣/学徒…）
```

### 岁时的公理（审查重点）

```
世界历法：360 日 = 1 年，四季各 90 日（state.js#seasonOf）
长岁：360 日 +1 岁（aging.js#DAYS_PER_YEAR = 360）
秋收：day % 360 === 240（一年一次）
月例/租金/放饷：day % 30 === 0（一年 12 个月，与 360 日自洽）
```
